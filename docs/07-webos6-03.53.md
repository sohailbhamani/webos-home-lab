# webOS 6.5 on firmware 03.53.45

The third TV is another 43UP8000PUR, the same model as the first one, but on
newer firmware: 03.53.45 (webOS 6.5.3) instead of 03.51.16. The home app is
the same QML app in the same place, and the overlay and boot hook work
unchanged. LG did change the home app between the two versions, though, so
two of the 6.5 patches no longer apply as they are. The set for this firmware
is in [`../patches/webos6-03.53`](../patches/webos6-03.53), one file per step,
same names as the 6.5 set.

## How different is the home app

Next to 03.51.16, 33 QML and JS files changed (about 800 lines) and four are
new. The bigger changes:

- The Recent Input card is now a `DeviceInfoTile` (it was `LastInputCard`). It
  has the same id and the same `visible` line in `AdShelf.qml`, so `01` still
  hides it.
- The recommended shelf (`HOME_SH_RECOMMENDED`) can now play a live preview
  of a channel when a tile has focus (`MediaPlayerComponent.qml`, the new
  `LivePlaybackInterfaces`), and it can show a Recent Input tile at the front.
- `Constants.js`, `ShelfList.js`, `RelatedList.qml` and `LiveTVComponent.qml`
  were reworked.

## Differences from 03.51.16, by patch

- `01`: in `PromotionInterfaces.qml`, `requestRecommendedAdData()` now resets
  `root.numberOfAdRequest` right after clearing `sponsoredAdData`, so the old
  hunk's context no longer matches. Same fix: return early, after both
  resets. The other four files in `01` apply as they are.
- `03`: the `visible:` line under the last cover rectangle in `MainView.qml`
  now also checks `shelfListContainer.state === "list"`. Same fix: make the
  cover transparent.
- `05`: also drops the "See User Guide" tile (type `"guide"`), as on webOS 7.
  Remote PC stays. This firmware adds the guide tile to the end of the
  connection shelf every time.
- `02`, `04`, `06` and `07`: the same changes as the 6.5 set, only at
  different line numbers.

## The LG Channels row: a setting, not a patch

After `01` to `04`, this firmware still showed one row above the apps:
"Free on LG Channels" (sometimes "Live on LG Channels" or a game promo), with
a Recent Input tile at the front. That's the recommended shelf, and it's
filled from LG's server as long as *Recommendations on Home* is on. Turning
the setting off removes the row. On this TV that was done with Glasshouse's
Privacy tab, which also turned off "Sponsored tiles on Home", screen saver
ads, the ACR consents and the rest. You can also do it by hand in the TV's
home settings. After that, the layout matches the first TV: apps right under
the background, connection shelf below.

## Screen and image sizes

Same as webOS 7: the panel is 4K, but the UI is drawn at 1920x1080 (the
framebuffer reports 1920x2160, two 1080-line buffers). The background is
rendered at 1920x1080 (about 750 KB) and copied to both `images/2k/` and
`images/4k/`.

This TV has 1 GB of RAM, about 1070 MB usable, with roughly 230 MB free once
everything is running. Keep backgrounds under 1 MB.

## Overlay and hook notes

- `hooks/70-homeqml-k` works as is. `/var/log/dbg-log` shows
  `failed_to_restore` after each relaunch, as on 03.51.16.
- The stock tree has the same two files whose names differ only in case
  (`AccuWeather_Logo.png` and `accuweather_logo.png`). Build the overlay on
  the TV (`cp -a` the stock `qml` tree to `homeqml-k/qml`), then push only the
  files you changed. See [`06-webos7.md`](06-webos7.md).
- Screenshots work with the capture service and `"method":"SCREEN"`, as on
  webOS 7. To reach tiles that are off screen, send remote keys with
  `luna://com.webos.service.networkinput/test/sendKeyCode` (`108` down, `106`
  right, `105` left, `103` up).
- `luna-send` over SSH prints nothing without a TTY here too. Use `ssh -tt`.

## Apps

- Glasshouse, App Update Blocker and its retry hook work as on webOS 7. See
  [`06-webos7.md`](06-webos7.md).
- Glasshouse mounts its own hosts table over `/etc/hosts` even with ad
  blocking off (it keeps the firmware update servers blocked). That table
  sits on top of the one from Life's Good Without Spying, so the update
  domains have to be added after it. That's what the retry hook does.
